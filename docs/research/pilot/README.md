# תשתית הפיילוט של Research Protocol v1

התשתית עונה על שאלות F1 עד F8 של הפרוטוקול המוקפא, סעיף 8.8, ומתעדת את הראיות שלהן. היא אינה מריצה את הניסוי הנעול ואינה מעניקה הסמכה. הקוד בחבילה `packages/research`, והיא אינה תלויה ב-`@dcc/core` או ב-`@dcc/db`.

## מקור האמת

הפרוטוקול המוקפא, `docs/research/onboarding-research-protocol-v1.md`, בגיבוב שנרשם ב-`onboarding-research-protocol-v1.freeze-1.md`. כל פקודה בודקת שהטקסט על הדיסק הוא הטקסט המוקפא, וכל רשומת ראיה נושאת את הגיבוב שלו.

## `params.json`: ההחלטות הפתוחות

כל פרמטר פתוח של הפרוטוקול, סעיפים 12.1 ו-12.2, מופיע כאן לפי המזהה שלו, במצב `UNSET`. אין ערכי ברירת מחדל. קוד שצריך ערך שלא נקבע נעצר עם `BLOCKED` ושם המזהה.

קביעת ערך נרשמת כך, ורק לפי ההליך הרשום של הפרמטר בפרוטוקול:

```json
"U12": {
  "state": "SET",
  "value": "...",
  "decidedBy": "מי החליט",
  "decidedAt": "2026-09-29",
  "basis": "על סמך מה, ולפי איזה כלל בסעיף 12.1"
}
```

הקובץ והיסטוריית ה-git שלו הם יומן סגירת הפרמטרים. סגירת פרמטר היא ביצוע של הפרוטוקול ולא תיקון שלו, ולכן היא אינה משנה את הטקסט המוקפא.

מזהה שמתחיל ב-`OP-` הוא פרמטר תפעולי של הפיילוט שהפרוטוקול אינו מגדיר. `OP-1` הוא התקרה הזמנית להרצות הפיילוט, שמתוכן נגזר U20.

## רשומת הראיה

כל מערכה של הפיילוט נכתבת לתיקייה מחוץ לריפו, `~/.dcc-pilot` או `DCC_PILOT_DIR`, לקובץ `evidence.jsonl` שמתווסף בלבד. כל שורה נושאת את הגיבוב של השורה שלפניה, ולכן שינוי, מחיקה או סידור מחדש מתגלים.

```bash
npm run -w @dcc/research pilot -- status
```

```bash
npm run -w @dcc/research pilot -- verify <תיקיית המערכה>
```

## איפה ריצה חיה, ומה עוצר אותה

- **תיקיית ריצה מחוץ לפרופיל.** כל ריצה של סוכן, העותק שלה, הבית הסינתטי וקבצי הזמניים יושבים תחת `<SystemDrive>\dcc-pilot`, כדי שאף נתיב שהסוכן מקבל לא יחשוף את המשתמש האמיתי. זו תיקייה רגילה, לא הגדרה.
- **PATH סינתטי.** רק קישור ל-`node.exe` ותיקיית `cmd` של git. כל תיקיית כלים שנמצאת תחת הפרופיל נדחית.
- **Job Object.** על Windows הסוכן רץ דרך `job-run.exe`, שמתקמפל מ-`packages/research/src/runner/job-run.cs` עם csc המובנה של ‎.NET Framework, בלי הורדה. כשהריצה נעצרת או מסתיימת, הקרנל הורג כל תהליך שהיא השאירה.
- **מה לא נאכף.** קריאות וכתיבות לקבצים, ורשת שאינה עוברת דרך הפרוקסי. כל אלה מזוהים לכל היותר, והבידוד של ריצה מסווג BLOCKED כשלא זוהה דבר, לעולם לא נקי.
