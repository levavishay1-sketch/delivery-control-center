# סבבי המחקר של הטמעת ריפוזיטורי (2026-09-29)

השינוי `onboarding-proves-itself` נבדק על ריפוזיטורים אמיתיים, סבב אחר סבב:
מודדים, מוצאים את החוליה החלשה, מתקנים **במנגנון** (כלל, תבנית, אימות, בנק
המשימות), ומודדים שוב. כל סבב משאיר כאן דוח לכל ריפו (מהתצוגה של ההרצה, דרך
`scripts/research/report-run.mjs`) ורשימת הממצאים ומה שונה בעקבותיהם.

ההרצות נעשות דרך ה-API של DCC (`scripts/research/onboard-repo.mjs`) עד שער
המסירה — על ריפו ציבורי שום דבר לא נמסר. המדידה: המשימות של הבנק, זרוע "בלי"
בצעד 4 וזרוע "עם" אחרי הבנייה, Sonnet 5 כמבצע, שופטי קוד תחילה ושופט Sonnet
שקורא את העותק רק כשהקוד לא יכול להכריע.

מגבלת המכונה: יש עליה node, npm ו-dotnet 10 (עם MSBuild ו-vstest של Visual
Studio); אין cargo, go, JDK, Python או pnpm. משימות build/test על ריפו שכלי שלו
חסר כאן הופכות למבחני כנות ("אי אפשר להריץ כאן — למה"), לא למבחני ביצוע.
